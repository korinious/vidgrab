VidGrab 0.1.0

Πρώτη έκδοση. Κατέβασε το VidGrab-0.1.0-win64.zip, αποσυμπίεσέ το και τρέξε το VidGrab\VidGrab.exe. Το FFmpeg και το Deno περιλαμβάνονται.

Δυνατότητες
- Λήψη από YouTube, X, Facebook και Instagram: επικόλληση συνδέσμου και προεπισκόπηση (τίτλος, μικρογραφία, διάρκεια).
- Ποιότητα: Καλύτερη / 1080p / 720p / Μόνο ήχος.
- Μορφή δίπλα στην ποιότητα:
  - MP4 (προεπιλογή) ή MKV με τις αρχικές ροές. Στο MP4 μετατρέπεται σε AAC μόνο ο ήχος, όταν χρειάζεται· η εικόνα δεν επανακωδικοποιείται ποτέ.
  - Για ήχο: MP3 (128/192/256/320 kbps) ή Αρχικό (m4a/opus, χωρίς μετατροπή).
  - Οι επιλογές θυμούνται στο επόμενο άνοιγμα.
- Ουρά λήψεων με πρόοδο, ακύρωση και επανάληψη (2 ταυτόχρονες από προεπιλογή). Κάθε λήψη κρατά τις δικές της επιλογές.
- Αν μια λήψη βγει σε χαμηλότερη ανάλυση από τη ζητούμενη, η κάρτα το δείχνει (π.χ. «1080p αντί 2160p»). Το κουμπί «Ξανά σε πλήρη ποιότητα» αντικαθιστά το αρχείο μόνο αν η νέα λήψη βγει καλύτερη· το παλιό αρχείο πηγαίνει στον Κάδο Ανακύκλωσης.
- Cookies από Firefox, Chrome, Edge ή αρχείο cookies.txt, για περιεχόμενο που απαιτεί σύνδεση.
- Ανθεκτικότητα:
  - Οι λήψεις γίνονται σε ξεχωριστό προσωρινό φάκελο, εκτός OneDrive.
  - Υπάρχουν επαναλήψεις όταν ένα αρχείο είναι κλειδωμένο από antivirus/OneDrive και αυτόματες επαναλήψεις σε HTTP 403.
  - Ένα υπάρχον αρχείο δεν αντικαθίσταται ποτέ (το νέο αποθηκεύεται ως « (2)»).
- Καθαρά μηνύματα σφάλματος στα ελληνικά. Αρχείο καταγραφής στο %LOCALAPPDATA%\VidGrab\logs\vidgrab.log.

Γνωστά θέματα
- Windows SmartScreen / antivirus: το VidGrab.exe δεν είναι ψηφιακά υπογεγραμμένο, οπότε στο πρώτο άνοιγμα μπορεί να εμφανιστεί «Τα Windows προστάτευσαν τον υπολογιστή σας». Πάτησε «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε». Κάποια antivirus μπορεί να εξετάσουν ή να μπλοκάρουν προσωρινά το αρχείο.
- VP9/AV1 σε MP4: στην «Καλύτερη» ποιότητα, όταν το YouTube δίνει την υψηλότερη ανάλυση (π.χ. 1440p/4K) μόνο σε VP9 ή AV1, το MP4 περιέχει αυτόν τον κωδικοποιητή, αφού η εικόνα δεν επανακωδικοποιείται. Τα σύγχρονα Windows και οι VLC/mpv τον παίζουν. Κάποιοι παλιοί players ή συσκευές μπορεί όχι· σε αυτή την περίπτωση διάλεξε 1080p, που συνήθως είναι H.264.
- Μετά από επαναλαμβανόμενο HTTP 403, η τελευταία προσπάθεια μπορεί να κατεβάσει χαμηλότερη ανάλυση. Η κάρτα το δείχνει και μπορείς να δοκιμάσεις ξανά αργότερα.
